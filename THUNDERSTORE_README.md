# MIO Archipelago Randomizer

The multiworld randomizer client for *MIO: Memories in Orbit*.

## Required Setup

Installing this package provides the MIO game client. You must also install the matching `mio.apworld` from the [latest release](https://github.com/ShackledMars261/mio-archipelago/releases/latest) into Archipelago's `custom_worlds` folder, then generate a new room with its YAML.

Archipelago 0.6.8 or later is required.

See the [project repository](https://github.com/ShackledMars261/mio-archipelago) for setup details, releases, and issue reporting.
